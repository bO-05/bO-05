### Hermes Warroom
> **Featured — AI Agent**

The AI on-call that never solves the same outage twice. Warroom turns Hermes Agent into an autonomous on-call engineer. When your service goes down, it investigates with 3 parallel subagents, fixes the issue, and writes a runbook skill so next time it's faster. Runbooks evolve through hill-climbing — only improvements survive.

**Tech:** Shell, AI Agents
